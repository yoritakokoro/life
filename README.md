# 五千万分之一 · 汉末三国的一生

> 五千万分之一 · 生于汉末
>
> 建安的英雄会被史书记住。可生在这个时代的绝大多数人，终其一生，也没有见过刘备、曹操或孙权。

一个浏览器里的汉末三国人生模拟：你随机降生为公元 150～280 年间的一个普通人，按年份推进，直到死去。模拟的年代下限是公元 350 年：活过这一年的人，结局写作“不知所终”。

- **出生**：按《续汉书·郡国志》各郡人口加权抽取郡县，再随战乱、逃亡与迁徙逐年修正；身份阶层（自耕农、佃户、屯田客、士家、工匠、商贩、奴婢、县吏、士族、边地族群）、家境、亲属均按概率生成。
- **历史是"天气"**：黄巾、董卓迁都、曹操屠徐州、官渡、赤壁、建安大疫、夷陵、五丈原、高平陵、灭蜀、归晋、八王之乱、永嘉之乱……按年份 × 地区改变战乱、饥荒、疫病、迁徙与征兵的风险。远方的大事以传闻的形式迟一两年传到你耳中。
- **偶尔的选择**：逃难或留守、应募或回家、卖田换粮、读书、成婚……选择改变概率，不决定结果。
- **极低概率的历史人物**：在涿县集市上远远看见刘玄德，在成都街头看见先主的车驾，长坂乱军中赵云从你身旁冲过……见过的人收入"名册"。
- **眼下所重**：每个人生阶段的心力放在哪里，由系统按年龄、性情、家境、身份、眼前的难处和过去的习惯判断；你可以拨一下方向，但人不一定全听你的。
- **性情与天资**：幼时的两个瞬间悄悄塑造性情（好问、谨慎、好动、执拗、随和、有主见），天资（巧手、强记、膂力、善察人意）要靠日后的行为才会显露。
- **家计**：每年自动结算田收、纺织、佣作、俸禄与口粮、衣物、赋税（算赋口钱更赋、曹魏户调、西晋户调式），结余进积蓄，亏空变债务；家资、家中余财与私蓄分开，成了户主才能动用家里的钱。债务压身时才弹出大决定：卖田、借钱、外出佣作、投靠豪强、举家逃债。
- **支用余财**：随时代、身份、性别、年龄与财力变化的消费菜单（多数时候你什么都买不起）；人物也会按性情自己花钱。
- **人生抉择**：三十多种随身份出现的抉择——田界之争、旧友来投、疫中照料邻家、路边弃婴、雇人代役、私改户口、山贼招揽、投奔坞壁、入道听经、逃奴赎身、寡妇改嫁；士人与官吏另有西园买官、群雄征辟、九品中正、名儒门下、五石散、收容流民、受贿、擅自开仓等。身份越高，抉择越多，见到名人的机会也越大。
- **出身与天资**：世家大族分郡中著姓与世代二千石的高门，有门第、联姻、门生故吏、家学，也要在董卓征召、官渡、荆州降曹、汉魏禅代、高平陵、吴亡这些关头站队；天资（巧手、强记、膂力、善察人意）与性情会在少年时引出一条路，但路通向哪里，要看出身和家境——同样过目不忘，寒门多半只能做书佐，士族子弟可以拜师治经。
- **底层之难与男女有别**：青黄不接、卖儿鬻女、豪强兼并、亭长勒索、征发转输、债务为奴、无钱下葬、交不起赋税而弃籍逃亡；许多选项因为没钱、没地、不识字而无法选择。女子要面对婆媳、"七出"、丈夫纳妾、守寡后夫家夺田、战乱中被掳；富人则可以乘车避难、闭坞固守、出钱免役、在别业里读书弹琴。
- **地域风俗**：南稻北粟、南方瘴疠、楚地巫鬼、齐鲁经学、凉州骑射、巴蜀盐井与蜀锦、交州海贸，各有地方事件与结局里的一段话。
- **亲疏、营生与故交**：每位家人都有自己的营生（农夫、佃户、工匠、县吏、军卒、出嫁……）和与你的亲疏，会因你的心力所在、日常的争吵与照顾、分家产、嫁女、给不给钱而变化；老来亲近的子女会奉养你。你会结交玩伴、同窗、同伍、同僚、乡邻，他们有自己的营生和命运，会借钱、接济、闹翻、和好、逃难失散，危难时也可以向他们求助。
- **月旦评与相人**：郭林宗、桥玄、许劭、司马徽、庞德公、山涛会品评有些身份或学问的人，一句评语可以让人一夜成名，也可以跟人一辈子；朱建平、管辂这样的相士，普通人偶尔也能碰上。评语看的是你的天资、学问和性情——评的人看得见你自己还不知道的天分。结局会回看这句话有没有应验。
- **城头易帜**：所在地易主时，在任的官吏要选择出迎新主、挂印归乡，还是追随旧主出奔；士人要决定是投书新主还是闭门观望。新主可能留任、贬斥，也可能把你下狱。对普通人来说，变的多半只是收租税的人、重新清点的户口和一张兑不了的征粮木券。
- **名册与交集**：名册共一百一十四人，魏、蜀、吴、群雄、晋各有补充。远远一见只看机缘（住在县城更容易碰上）；近身的交集——被曹公问屯田之弊、在丞相府考课时自陈过失、高平陵前夜被人试探、合肥城中应募八百敢死、随邓艾翻越阴平——只属于在任的官吏和行伍中人。得到名人赏识的人仕途会顺一些，但从田间走到郡守、将军，几乎不可能，只是并非绝对。
- **东晋十六国（317～350）**：衣冠南渡、石勒称赵王、祖逖北伐、王敦与苏峻之乱、洛阳之战、石虎篡位与苛政、慕容皝称燕王、咸康土断、括取民女入宫、桓温灭成汉、后赵崩溃、冉闵杀胡令；相应的法令（侨置州郡、咸康土断、李雄之治、石勒之制、石虎苛政、杀胡令、慕容氏侨郡、张氏保凉）、地方事件（坞主、流民南渡、流民帅、羯兵）和人物（王导、祖逖、陶侃、桓温、王羲之、石勒、石虎、冉闵、慕容皝、李雄）。
- **求学**：各政权的学校按史实设置，并作为本地法令显示：东汉洛阳太学（射策取士）、荆州学官、魏太学（通一经补文学掌故）、蜀汉太学、吴五经博士、晋太学与国子学、后赵太学、东晋太学、慕容东庠。识字的青年可以去求学，学问逐年增长、结识同窗，几年后考试，及第就补官，落第可以再考一次；战乱中学校散了，也就回家。
- **出仕的门路随时代而变**：灵帝西园卖官时，家财万贯的人（商贾也可以）能花钱或赊钱买个县令；曹操下《求贤令》后，有一技之长的寒门可以毛遂自荐；九品中正之后，寒门要备厚礼拜见中正才能评得中品——"上品无寒门，下品无势族"。
- **营生的五条路**：佃农（可能被征发、募兵成为兵卒）；乡里经营（亭长、里正、游徼、乡啬夫，要看家底和名望）；州郡文职（书佐、计吏、县长、县令……受人脉和时局制约）；幕府谋议；行伍部曲。后两者政治风险大：依附的势力败亡时，幕僚要选择改投新主、回乡隐居还是为旧主守节，可能被当作余党下狱；军队覆灭时，军官可能被俘斩首，投降的会被降级。
- **女子的上升之路**：东汉每年八月在洛阳一带阅视良家女子；孙皓简阅将吏之女（十五六岁选不中才许出嫁）、晋武帝聘选公卿以下子女并禁天下婚嫁、石虎括取民女——女儿可能被选入后宫，从宫人、采女做起，极少数能升到美人、贵人、夫人，皇后几乎不可能（郭女王、卞夫人是先例）；位分高了，也会卷入巫蛊之祸。吴亡时孙皓的宫人被运往洛阳，晋武帝死后放出一批。平民女子也可能被显贵纳为妾，门第跟着变了，孩子却是庶出。
- **各国的后宫与仕进**：魏（掖庭阅选；明帝时夺回已嫁吏民的士家女改配士卒、选入掖庭）、蜀（采选几乎总被侍中董允谏止："古者天子后妃之数不过十二"）、吴（选江东良家女，潘夫人出身织室）、晋、东晋、后赵、成汉各有选女之制；仕进上，东汉举孝廉（二十万人举一人）、蜀汉丞相府从小吏中拔擢、吴国寒门要投大族门下做宾客或从军、后赵石勒也清定九品。
- **支用余财选具体对象**：游历时每个去处都列出治安、盘缠、路上日数和风险，敌国关津不通、正在打仗的地方去不了；路上可能遭劫、染病，极少数回不来。送礼、请酒、结拜可以选具体是哪位朋友，添置衣物可以选具体是哪位家人。
- **夫妻与儿女**：配偶会病倒（请医、请巫、守候）、会争吵，出嫁的女儿想回娘家要看婆家脸色；孩子要教（严管、顺性、带着干活），会闯祸，长到十几岁要定出路（读书、学手艺、种地、做买卖），出路决定他后来的营生。妾会出现在家人和户籍简里（写作"妾"），妾所生的孩子标为"庶出"，结局的家人栏也会列出。
- **晋升之路**：行伍中每年按资历、战功、膂力、识字、出身、有无提携和政令决定能否升迁（军卒→屯长→军司马→校尉→将军）；寒门官吏每年考课，政绩积累名声，可从书佐、计吏一路做到县长、县令，有人提携才可能做到郡守。唯才是举、北伐、慕容氏举贤让晋升容易些，士亡法、石虎苛政、罢州郡兵、九品中正（对寒门）则更难。
- **株连有前因后果**：清洗来临时，先写明你与失势一方的牵连（岳父是门生、曾受举荐、族兄在其府中任职……），再让你选择连夜出逃、闭门待罪，还是上书自陈、揭发旧交；死因也会写清楚是哪一案。
- **女子与阶层**：女子不能出仕；丈夫被征发时独自撑家、父亲死后田产归兄弟、士族女子的联姻、婢女被主人纳妾、商家妇当垆卖酒、寡妇被旌表为"贞妇"、石虎括取民女入宫——同为女子，阶层不同，处境也不同。
- **本郡情形**：舆图下方显示所在郡的户口、治安、粮价和流民，逐年变化：周边战乱和灾荒会让流民涌入、粮价上涨，易主和盗贼会让治安变坏。地方上的随机事件以史实为本，既有开仓赈贷、大姓闭籴、招抚流民、常平仓这类常见的地方事务，也有黑山贼、白波贼、泰山贼、葛陂黄巾、青州黄巾、关中流民入荆州、山越、江贼、鲜卑、乌桓、羌乱、南中夷帅、秦雍流民入蜀等特定时地的事。治安差了更容易遭劫，粮价高了买粮更贵，流民多了工钱更贱。逃难、迁徙、逃债时，抉择上会写出本郡和目的地的对比，好有个判断。
- **身边人的事**：朋友做了官、发了财、娶亲生子、战死、被诬下狱，同窗成了经师，分家的兄弟日子越过越好——你怎么反应，随性情而定：随和的人真心道贺，好胜（善妒）的人暗暗较劲、从此更想出人头地。
- **人生的回响**：年轻时的选择会在五到二十年后回来找你：救过的朋友替你还债、举荐你做官；当年躲开的朋友从边地回来，与你在集上撞见；卖掉的孩子有了下落，可以凑钱赎回；争过田界的邻家一直别着劲，让过一步的邻家来帮你盖房。结局页会把这些回响列出来。
- **结局：一生所历**：历经几个政权、居住过的郡、游历过的地方、见过最贵的粮价、动荡的年头、交给官府的赋税、经历的法令、结识的人物、朋友、子女、亲手做出的抉择。
- **同席交游**：高门子弟、郡守刺史、名满一时的人，会在宴会、拜访、清谈雅集中结识同时代的人物；门第越高、官越大，交游越广，不限于本郡。普通人仍然只能远远看一眼。
- **一件大事，两种说法**：庶民听到的是"新皇帝登基，改元黄初。乡里的老人说：汉朝亡了"；士族、官吏、读书人看到的是汉帝刘协下诏禅位、曹丕繁阳亭受禅、汉帝被奉为山阳公。黄巾、迁都、迎天子、官渡、长坂、禅位、称帝、托孤、五丈原、高平陵、灭蜀、魏晋禅代、灭吴都有两种写法。
- **称呼随居住地而变**：同一个人，魏地称"曹公、魏王、武皇帝"，蜀地称"刘使君、汉中王、先帝"和"丞相"，吴地称"孙将军、吴王、至尊"。
- **前因后果**：城池易手的前一年，在任官员先读到军报，士族在族中议论，庶民听到传言、看见逃难的人；在任官员会为本方的战事筹粮、写檄文、安置伤兵；远方的大事不再一律写作"你对此一无所知"。
- **自动支用**：可以单独开启，每年按性情、眼下所重和家境替你花一部分余财。花法随身份而来：出门游历（目的地看年代和是否同属一方）、捐资修祠、办义塾、收葬饿殍、设粥棚、捐献军资、宴请县吏、拜会三老、结拜、结交游侠；穷人养猪崽、请医、赎回被卖的亲人、给女儿备嫁妆；富户放债、买百亩田、修坞壁、养宾客部曲、修藏书楼、招邀名士雅集、为先人修墓立碑（薄葬令下不行）、打点举荐或中正官。这些花费会真的改变战乱中的安危、仕途、名声、结识名人的机会和家人的寿数。
- **此地法令**：三十多条法令政策按「地点 × 年份 × 统治者」生效，户籍栏里随时可见，生效时在编年里贴出告示，迁居或城头易帜后会随之改变：党锢之禁、西园卖官、修宫钱、董卓小钱、袁术横敛、袁氏宽纵、荆州学官、东州兵、五斗米道之治、屯田制、户调制、士亡法、禁酒令、薄葬令、唯才是举、校事、九品中正、直百五铢、蜀科、都江堰堰官、闭关息民、北伐征发、世袭领兵、大泉当千、吕壹典校、孙皓苛政、泰始律、占田课田、罢州郡兵……它们真的改变赋税、征兵、收成、钱的价值、寒门与士族的仕进、贪赃被查的可能，以及在任者被告发下狱的风险。
- **家境之差**：家境分赤贫、贫寒、温饱、小康、殷实、富足、豪富几档，并随田产、人口、财力逐年变化（户籍简里随时可见）。同样是一年，赤贫人家的孩子剥榆树皮、光脚过冬、被送去给人放牛，弟妹可能被送人；小康人家过年有新衣、腊日分一块肉；富户的孩子有长工、先生、丝履；高门子弟有乳母和小僮，族祭时捧着祭器走在最前面。幼年还会遇到按家境出现的抉择：把最后半块饼让给弟妹、替大户看鸭子换一升米、处置偷粮的佃户孩子、替挨打的小僮认错。连生病、失火、遭贼的写法和轻重，也随家境不同。
- **出生时的家境说明**：降生页用白话说明你家在当时处在什么水平（每口人几亩田、够不够吃、十户人家里有几户比你难），不熟悉汉末也能看懂。
- **传家**：死后可以以子孙之身继续，家谱一代代接下去。
- **后记与身后**：结局按你的身份与死因写一段后记，并记下你死后故乡又经历了什么；家人一栏列出每位亲人的生卒与结局。
- **户籍简**：按走马楼吴简的格式（大男/大女、使男/使女、未使，虚岁、廿卅卌）记录你家的户口。
- **汉纪 · 一格一年**、生存曲线、同时代人的死因、墓志、同一时辰降生的另外三人。
- **从军之路**：成年男子可以把"眼下所重"放在"投军从戎"，乱世里更容易被收进军中；有膂力或尚武的人更常被募兵找上门。士族子弟或天生武勇的人投军，起步就是屯长。
- **名字分贵贱**：士族、县吏之家多取雅名（彧、琬、徽、珮）与吉字小名（阿璋、阿凤）；农家多取贱名（狗、丑、豚、黑）、排行或"弟""取"之类盼子的名字；奴婢的名字由主人起（奴福、秋菊）。生成的人物（你、家人、朋友、配偶、情人）不会与史书上的名人同名，也不会与名人的表字撞上（不会有一个种地的“赵云”或“刘玄德”），小名里也去掉了“阿斗”“阿瞒”。士族女子读《女诫》、习女红，婢女在灶下与针线间度日；寡妇改嫁的可能也随门第而异。

- **娶名人之女**：高门子弟极少数可能被曹操、袁绍、刘表、荀彧、张昭、诸葛瑾、司马懿、王导看中，娶他的一个女儿（这些人的女儿史书只记下了一部分的婚配），岳家的兴衰也会落到你头上。
- **郡望**：生在颍川、河内、汝南、琅邪、吴郡、沛国、鲁国、陈留、泰山、会稽、京兆的士族，可能就是荀、钟、司马、袁、诸葛、王、陆、曹、夏侯、孔、蔡、羊、虞、杜这些名族的旁支——更容易在族祭、省亲时见到荀彧、荀攸、钟繇、司马懿这些族人，族中有人当权时仕途也顺一些；族中的荣辱也是你的荣辱（董卓杀京城袁氏五十余口、诸葛恪夷三族、司马炎受禅）。同郡同姓的寻常人家，只是"出了五服的同宗"。
- **庶出**：士族与富家的孩子可能是妾所生。礼法上嫡母才是"母亲"，生母见了嫡母要行礼；父亲死后分家，田宅大半归嫡出的兄弟，生母可能被打发出门；说亲时对方先问"嫡出还是庶出"，女儿的嫁妆也薄一半。
- **小兵眼里的名战**：广宗、界桥、彭城、濮阳、宛城、下邳、易京、官渡、北征乌桓、赤壁、潼关、雒城、合肥、定军山、樊城、襄樊、夷陵、街亭、石亭、陈仓、木门、五丈原、襄平、东兴、灭蜀、灭吴、宁平城都有士卒所见的细节；其中十场有关头的抉择——乌巢粮尽后往河边逃还是投降（降卒七万余人被坑杀）、赤壁火船来时跳江还是往岸上跑、樊城大水中随于禁投降还是随庞德死战、江陵失守后回家还是留在关羽身边、夷陵火起往马鞍山跑还是投北岸黄权（随之降魏）、襄平城破前缒城、东兴浮桥……军官另有带兵的所见。
- **战事里的不同身份**：大战之年，农夫可能被征为民夫转运粮草（北伐翻越秦岭栈道、王濬在蜀中造船、官渡与赤壁的转输），可以去、雇人代役或逃进山里；妻子送丈夫去运粮；商人把粮草卖给军中，也可能被强征；幕府中人随军出征，掌文书、参军议，也可能死于军中的疫病。
- **平民的营生**：开春种什么（照旧、种豆、种桑麻交户调、种菜进城卖）；农闲的副业（烧炭、编草鞋织席、捕鱼；女子纺线、养猪养鸡、做帮佣、缝补浆洗），副业会在之后几年的家计里带来进项；换工借牛、合伙修渠（之后几年收成更好）、兵荒后开垦荒田（原主可能回来要地）、进城做佣工或去铁官做工、给大户人家做乳母（自己的孩子可能饿死）、户调交不齐、乡里红白事随礼、老来被推为里中父老、冒险贩私盐；春社秋社、腊日祭祀、看说书、斗鸡这样的小事也写进了日常。
- **出身决定日常**：富户的孩子不必放牛拾柴、跟着母亲去河边洗衣，有田有仆的人家管的是佃客和账目，商家、工匠、小吏之家的女子各有各的活计；幼时两个塑造性情的瞬间，也按出身（贫家、富户、士族、商家、奴婢、牧民、山地族群）换成不同的场景；朋友的来历（族中家塾的同学、闺中姐妹、讲论经义的同道）也随门第而异。
- **私情**：极少数人会有一段不伦之情——同里服役者的妻子、常来挑水劈柴的邻人、同僚的妾、丈夫的门客、主人的侍妾。每年都可能败露：按《二年律令·杂律》"与人妻和奸，及其所与，皆完为城旦舂"；女子还可能以"七出"中的"淫佚"被休、孩子留在夫家；对方丈夫可能打上门、私了索钱，极少数会动刀；士族则败于清议，丢官降品；奴仆与主人侍妾私通，多半被活活打死。也可能是你发现配偶有了私情：男子可以休妻、告官、找人算账，女子只能忍、去闹（反被说"妒"）或求娘家出面。
- **男子的不伦**：同里服役者之妻、亡兄的寡嫂（"复兄弟之妻"黥为城旦舂，乡论叫"盗嫂"，可能被逐出宗族）、家中新买的婢女（律令不禁，妻子却会卖掉她或回娘家）、被同僚拉去倡家（一掷千金，或从此成了常客）、西晋咸宁太康以后士大夫间的男宠之风。
- **罪与罚**：饥年偷大户的粮、集市斗殴失手打死人（亡命他乡、投案自首或凑钱私了）、为父复仇后自首（可能被县长感念孝义而遇赦旌表，也可能弃市）、乱世盗墓、钱轻时盗铸钱（"盗铸钱及佐者，弃市"）、樗蒲六博输光口粮、被争田的邻家诬告。判了刑的人剃发戴钳做刑徒（髡钳城旦、黥为城旦、罚作），可能累死在工地上；家里有钱可以赎罪；亡命的人会被认出押回原籍，而天子的大赦随时可能一笔勾销。
- **同性之情（约 6% 的人生）**：男子爱上同为男子的挚友、女子爱上同里的姑娘；婚后才发觉的，另有一套经历（压下心思做个本分的丈夫/妻子、瞒着家人暗中往来、狠心断了），暗中往来一旦被撞破，男子多受乡论讥笑、妻子回娘家，女子则可能被婆家禁足甚至以"淫佚"休回，可以藏在心里、吐露或躲开；女子之间约定一辈子做最亲的姐妹，却拗不过"女大不中留"；后宫宫人之间结为"对食"（应劭："宫人自相与为夫妇名对食"）。史书只在帝王"断袖"、宫人"对食"、晋人"男宠"处留下几笔，朋友栏里两情相悦的人标为“心上人”，结局会替你记下这段情分。
- **爱好与才艺**：少年时（或成年后安稳下来）会迷上一样消遣，可选的爱好由家境决定——寻常人家唱山歌、角抵、编竹器、钓鱼捕鸟、斗鸡、六博，女子刺绣；士族富户弹琴、下棋、骑射田猎、清谈（正始以后）；识字的人写字、作诗赋、读医方、学算术。爱好逐年精进，花钱的爱好家道中落就得放下。极少数有天分的人会以此出名，结果也随出身而异：寒门写得一手好字被县廷招去做书佐、算术好做了计吏、画得好成了给墓室作画的画工、歌喉好被豪强雇去做歌者（从此算"倡优"之流）、角抵蹴鞠出众被军中看中；士族则在名士宴集上抚琴、诗赋被人拿来比王粲刘桢、清谈出名被人品评。
- **先天之疾与痼疾（低概率）**：古人没有今天的病名，只写他们看见的样子——孤僻寡言、专于一事（约 1%：寒门被叫作"呆子"、受人欺哄，偶有老匠人看出你的细致收你为徒；士族里被说"性僻"，若遇名士品题，便成了"性介而才奇"的异才）、聋哑、目盲（自古乐官多用瞽者，寒门多以卜筮唱曲为生）、跛足（律称"罢癃"，免于兵役）、兔缺、侏儒（豪门买去做俳优）、痴愚（士族照样护着，晋惠帝也是这样的人）、痫症（被说成鬼魅附身，近水近火都有危险）。它们影响识字、说亲、兵役与营生，家世越高，受到的庇护越多。成年后还可能得上虚劳咳血（穷人无从将养）、消渴（富贵病）、风痹，以及极少数的疠风（被赶出里门，秦汉律令要迁往"疠所"）。户籍栏里显示"体况"。

- **妻随夫贵**：女子出嫁后，阶层、家计和日子跟着丈夫走——嫁进士族就主持中馈、教子读经，丈夫做了县令就随任住进官舍，丈夫升迁、罢官、俸禄多少都会落到你身上；嫁给豪强要管坞壁里上百口佃客部曲，做显贵的妾要给正室"立规矩"。士族高门的家主、乡里豪强的男子也有各自的日常。做了名人的妾，就一直住在他的府里，娘家的债务、外面的营生与你无关，交友只能靠书信；他进位为公、为王、称帝时，府邸变成宫室（曹操的魏公宫与魏王宫、刘备的汉中王宫与成都皇宫、孙权的吴王宫与建业太初宫），府里与宫里各有日子和抉择（新人争宠、娘家求助、回家省亲、女儿议亲或公主下嫁）；战乱、饥荒、疫病也按府中和宫中的视角来写。他死后，宫中的姬妾迁居别宫守灵，曹操的姬妾上铜雀台，袁绍的宠妾被刘夫人所杀，刘表的家眷随刘琮北迁青州，袁绍的妻室在邺城破后得到曹操的慰劳。

- **改朝换代时的后宫**：董卓迁都时宫人被驱赶西行，献帝东归时在曹阳被乱兵追杀掳掠（"宫人食枣菜"），次年随天子到许；汉献帝禅位后，有位分的随山阳公迁往浊鹿城；蜀亡时魏人把蜀宫宫人赐给无妻的将士，李昭仪说"我不能二三屈辱"后自尽——你可以效仿、听天由命或托人求情；魏亡时随陈留王去邺城；吴亡时孙皓的后妃宫人被送往洛阳；永嘉之乱时洛阳宫中的人被杀、被掳往平阳或趁乱逃出。天子驾崩时，有子的嫔妃随儿子去封国做王太妃，无子的迁居别宫，低位宫人可能被放出宫。
- **世风**：统治者的作风决定了一方的气氛，在「此地法令」最上方以"世风"显示，并在编年里时时让你感到：宦官专权、黄巾之后、董卓暴虐、李郭乱政、曹操的法令严峻（割发代首、唯才是举、校事刺探、孔融崔琰因言获罪）、魏法整肃（禁私复仇）、司马氏专政（"名士少有全者"、嵇康《广陵散》）、刘备的宽仁与诸葛亮的法度、蒋费守成、黄皓用事、江东大族、二宫之争、孙皓的剥面凿眼与宴上记过、刘表的荆州宽和、袁术僭号、公孙瓒抑压士族、笮融浴佛、张鲁义舍、士燮出入的排场、公孙度严法、晋初斗富、八王之乱（"何不食肉糜"）、永嘉丧乱、"王与马共天下"、石勒禁称胡、石虎暴虐、李雄宽和、慕容招徕。世风也会改变本郡的治安；在严苛或暴虐的统治下，士人与官吏偶尔会因一句话获罪，极少数被处死。
- **趣闻**：史书和《世说新语》里的段子，按年份、地方和身份偶尔碰上（编年里标作"趣闻"）：曹营行军时的望梅止渴、曹操"梦中好杀人"、刘备鞭督邮与髀肉复生、吕布辕门射戟、祢衡击鼓、司马徽"大好"、诸葛亮笑刘备结毦、长坂桥头的张益德、曹冲称象、孙权船受箭（"生子当如孙仲谋"）、"辽来"止啼、吴下阿蒙、王粲葬礼上满堂学驴叫、"鸡肋"、七步诗、孙权钓台泼水、"诸葛子瑜之驴"、司马懿收下女装、"死诸葛走生仲达"、邓艾"艾艾"、钟会访嵇康、刘伶"诸君何为入我裈中"、"乐不思蜀"、刘毅比晋武帝于桓灵、王戎钻李核、潘岳掷果盈车、惠帝问蛤蟆是官是私、周处除三害、闻鸡起舞、陶侃运甓、东床坦腹、石勒听《汉书》。每一条都有出处，一辈子大约碰上零到两条。
- **孤儿**：极少数人一出生就成了孤儿（乱兵、饥荒或大疫中父母双亡）；幼年失去双亲的，去处随出身、性别和世道而不同——士族由族中伯父收养（族人可能侵吞你家的田宅，长大后可以告到郡里、请族老主持或自己挣）、寻常人家由叔父或外祖家收养（叔父可能把你家的地算作自家的）、被没有孩子的老人领走、乱世里被将领收作"假子"（十五岁编入部曲做屯长，刘封就是这样的出身）、女孩被收作养女或童养媳（十五岁与养家儿子成婚）、被族人卖作奴婢，或流落县城讨饭（之后被军队收去、被大户收作僮仆或被老夫妇收养）。寄人篱下、族学、军营、讨饭各有各的日常。
- **流民**：穷人家逃难、逃荒、逃债，可能到了异乡没有田、没有户籍，成了流民——草棚、粥棚、插草标卖孩子、不许入城；各时期另有关中流民入荆州、徐州人渡江、六郡流民随李特入蜀、"乞活"、永嘉南渡。流落一年多后要自己拿主意：投豪强做佃客、应招抚编户分田（魏晋）、应募屯田（曹魏）、跟"乞活"走、上山入伙、继续南渡、随流民入蜀；女子还可以嫁给当地人家或卖身为婢。孩子则随父母落脚。
- **落草为寇**：从山贼招揽、流民或乞活入伙，所在的山头按时地而定——黑山（张燕，205 年率众降曹，你被编入曹军）、白波（护驾东归后被击散）、泰山（臧霸、孙观，198 年归曹）、荆州宗贼（190 年刘表诱杀其头领五十五人）、江贼（甘宁的锦帆）、乞活，或寻常山贼。山上有分赃、下山劫掠、偷偷回家、官军围剿（可能被斩首示众）、打出名气做小头目；官府招安时可以下山归田、下山投军或留在山上。女子可能在乱世中被掳上山，顺从、伺机逃走或宁死不从，之后随山寨的命运被放回乡里或被配给士卒。
- **家道中落**：家境从殷实以上一路跌落时，会按身份写出中落的样子——士族遣散僮仆、卖藏书、门生不来；商家货船沉没、铺子盘出；丢官的人门庭冷落；富户一块块卖田。成年的户主要拿主意：变卖祖产、咬牙撑门面，还是投靠富亲戚。此后十年里，日常也是中落人家的日常（当锦袍、路过自家旧田）。也有人一出生就是"祖上阔过"的人家：祖父做过县令、党锢时败落的郡中大姓、遭了官司的商家。
- **名人的生年与身份**：顶部"史书上的这一年"会写出这一年出生的名人（如"161年，刘备出生。"，只收史有明载生年的约六十人）。名册里的人物按身份出现在相称的场合：武将在劳军的校场、庆功的宴席上，谋臣在府中议事、作为使者赴宴，名士在讲经的集会上（清谈雅集要到正始年间以后才有），医者、相士、方士、宗教人物和孟获只在他们自己的场景里出现；称帝之后的君主，只有有官位或出身高门的人才能远远望见——在天子巡幸的道旁，或在殿下。
- **文字与处境相符**：已故或不在身边的父母不会再出现在日常里（孤儿的婚事、逃难、借债由叔父、养母、族中长辈做主），未婚的人没有丈夫妻子的日常，家境不再富裕的人家不再有僮仆车马，讨饭的孩子不会有"你家"的家计，家人与朋友不会重名。
- **墓志**：迁居与"一生未曾离开"不再互相矛盾——迁居却没出过本郡的写"迁居几次，都没有离开某郡"，出过郡的列出住过的郡；墓志也会记下幼失怙恃由谁养大、祖上曾阔、家道中落、做过流民、上山入伙或被掳上山、卖身为婢或做侍女、没入官府、为主人之妾、随子之国为王太妃；新增几项成就（孤儿长大成人、流民重新有了地、活着下了山、中落后重振家业、从婢女成为妾、从官婢升为嫔妃）。
- 每一世都有"命数"，可以重现同样的出身。

**这是历史概率模拟，而非精确人口学重建。**

## 运行

纯静态页面，没有构建步骤。直接用浏览器打开 `index.html`，或者：

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000
```

也可以直接部署到 GitHub Pages。前世与名册只保存在浏览器的 localStorage 中。

## 结构

| 文件 | 内容 |
|---|---|
| `js/data.js` | 郡国人口、各区人口指数、政权时间线、年号、族群、姓名、身份阶层 |
| `js/history.js` | 编年大事（效果按年份 × 地区）、战役、追随者旅程、历史人物与邂逅、地方风物、日常 |
| `js/engine.js` | 逐年模拟引擎（可确定性重现：同一命数 + 同样选择 = 同样一生） |
| `js/ui.js` | 界面、播放、舆图、汉纪、生存曲线、墓志、名册与前世 |
| `css/style.css` | 帛书与竹简的视觉 |

引擎不依赖 DOM，可以在 Node 中加载 `data.js`、`history.js`、`engine.js` 后批量模拟。
