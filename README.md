# 一世·汉末 · One Life in the Late Han

> 五千万人之一 · 生于汉末
>
> 建安的英雄会被史书记住。可生在这个时代的绝大多数人，终其一生，也没有见过刘备、曹操或孙权。

一个浏览器里的汉末三国人生模拟：你随机降生为公元 150～280 年间的一个普通人，按年份推进，直到死去。

- **出生**：按《续汉书·郡国志》各郡人口加权抽取郡县，再随战乱、逃亡与迁徙逐年修正；身份阶层（自耕农、佃户、屯田客、士家、工匠、商贩、奴婢、县吏、士族、边地族群）、家境、亲属均按概率生成。
- **历史是"天气"**：黄巾、董卓迁都、曹操屠徐州、官渡、赤壁、建安大疫、夷陵、五丈原、高平陵、灭蜀、归晋、八王之乱、永嘉之乱……按年份 × 地区改变战乱、饥荒、疫病、迁徙与征兵的风险。远方的大事以传闻的形式迟一两年传到你耳中。
- **偶尔的选择**：逃难或留守、应募或回家、卖田换粮、读书、成婚……选择改变概率，不决定结果。
- **极低概率的历史人物**：在涿县集市上远远看见刘玄德，在成都街头看见先主的车驾，长坂乱军中赵云从你身旁冲过……见过的人收入"名册"。
- **眼下所重**：每个人生阶段的心力放在哪里，由系统按年龄、性情、家境、身份、眼前的难处和过去的习惯判断；你可以拨一下方向，但人不一定全听你的。
- **性情与天资**：幼时的两个瞬间悄悄塑造性情（好问、谨慎、好动、执拗、随和、有主见），天资（巧手、强记、膂力、善察人意）要靠日后的行为才会显露。
- **家计**：每年自动结算田收、纺织、佣作、俸禄与口粮、衣物、赋税（算赋口钱更赋、曹魏户调、西晋户调式），结余进积蓄，亏空变债务；家资、家中余财与私蓄分开，成了户主才能动用家里的钱。债务压身时才弹出大决定：卖田、借钱、外出佣作、投靠豪强、举家逃债。
- **支用余财**：随时代、身份、性别、年龄与财力变化的消费菜单（多数时候你什么都买不起）；人物也会按性情自己花钱。
- **人生抉择**：三十多种随身份出现的抉择——田界之争、旧友来投、疫中照料邻家、路边弃婴、雇人代役、私改户口、山贼招揽、投奔坞壁、入道听经、逃奴赎身、寡妇改嫁；士人与官吏另有西园买官、群雄征辟、九品中正、名儒门下、五石散、收容流民、受贿、擅自开仓等。身份越高，抉择越多，见到名人的机会也越大。
- **出身与天资**：世家大族分郡中著姓与世代二千石的高门，有门第、联姻、门生故吏、家学，也要在董卓征召、官渡、荆州降曹、汉魏禅代、高平陵、吴亡这些关头站队；天资（巧手、强记、膂力、善察人意）与性情会在少年时引出一条路，但路通向哪里，要看出身和家境——同样过目不忘，寒门多半只能做书佐，士族子弟可以拜师治经。
- **底层之难与男女有别**：青黄不接、卖儿鬻女、豪强兼并、亭长勒索、征发转输、债务为奴、无钱下葬、交不起赋税而弃籍逃亡；许多选项因为没钱、没地、不识字而无法选择。女子要面对婆媳、"七出"、丈夫纳妾、守寡后夫家夺田、战乱中被掳；富人则可以乘车避难、闭坞固守、出钱免役、在别业里读书弹琴。
- **地域风俗**：南稻北粟、南方瘴疠、楚地巫鬼、齐鲁经学、凉州骑射、巴蜀盐井与蜀锦、交州海贸，各有地方事件与结局里的一段话。
- **亲疏、营生与故交**：每位家人都有自己的营生（农夫、佃户、工匠、县吏、军卒、出嫁……）和与你的亲疏，会因你的心力所在、日常的争吵与照顾、分家产、嫁女、给不给钱而变化；老来亲近的子女会奉养你。你会结交玩伴、同窗、同伍、同僚、乡邻，他们有自己的营生和命运，会借钱、接济、闹翻、和好、逃难失散，危难时也可以向他们求助。
- **月旦评与相人**：郭林宗、桥玄、许劭、司马徽、庞德公、山涛会品评有些身份或学问的人，一句评语可以让人一夜成名，也可以跟人一辈子；朱建平、管辂这样的相士，普通人偶尔也能碰上。评语看的是你的天资、学问和性情——评的人看得见你自己还不知道的天分。结局会回看这句话有没有应验。
- **城头易帜**：所在地易主时，在任的官吏要选择出迎新主、挂印归乡，还是追随旧主出奔；士人要决定是投书新主还是闭门观望。新主可能留任、贬斥，也可能把你下狱。对普通人来说，变的多半只是收租税的人、重新清点的户口和一张兑不了的征粮木券。
- **名册与交集**：名册共七十九人。远远一见只看机缘（住在县城更容易碰上）；近身的交集——被曹公问屯田之弊、在丞相府考课时自陈过失、高平陵前夜被人试探、合肥城中应募八百敢死、随邓艾翻越阴平——只属于在任的官吏和行伍中人。得到名人赏识的人仕途会顺一些，但从田间走到郡守、将军，几乎不可能，只是并非绝对。
- **同席交游**：高门子弟、郡守刺史、名满一时的人，会在宴会、拜访、清谈雅集中结识同时代的人物；门第越高、官越大，交游越广，不限于本郡。普通人仍然只能远远看一眼。
- **一件大事，两种说法**：庶民听到的是"新皇帝登基，改元黄初。乡里的老人说：汉朝亡了"；士族、官吏、读书人看到的是汉帝刘协下诏禅位、曹丕繁阳亭受禅、汉帝被奉为山阳公。黄巾、迁都、迎天子、官渡、长坂、禅位、称帝、托孤、五丈原、高平陵、灭蜀、魏晋禅代、灭吴都有两种写法。
- **称呼随居住地而变**：同一个人，魏地称"曹公、魏王、武皇帝"，蜀地称"刘使君、汉中王、先帝"和"丞相"，吴地称"孙将军、吴王、至尊"。
- **前因后果**：城池易手的前一年，在任官员先读到军报，士族在族中议论，庶民听到传言、看见逃难的人；在任官员会为本方的战事筹粮、写檄文、安置伤兵；远方的大事不再一律写作"你对此一无所知"。
- **自动支用**：可以单独开启，每年按性情、眼下所重和家境替你花一部分余财。花法随身份而来：穷人养猪崽、请医、赎回被卖的亲人、给女儿备嫁妆；富户放债、买百亩田、修坞壁、养宾客部曲、修藏书楼、招邀名士雅集、为先人修墓立碑（薄葬令下不行）、打点举荐或中正官。这些花费会真的改变战乱中的安危、仕途、名声、结识名人的机会和家人的寿数。
- **此地法令**：三十多条法令政策按「地点 × 年份 × 统治者」生效，户籍栏里随时可见，生效时在编年里贴出告示，迁居或城头易帜后会随之改变：党锢之禁、西园卖官、修宫钱、董卓小钱、袁术横敛、袁氏宽纵、荆州学官、东州兵、五斗米道之治、屯田制、户调制、士亡法、禁酒令、薄葬令、唯才是举、校事、九品中正、直百五铢、蜀科、都江堰堰官、闭关息民、北伐征发、世袭领兵、大泉当千、吕壹典校、孙皓苛政、泰始律、占田课田、罢州郡兵……它们真的改变赋税、征兵、收成、钱的价值、寒门与士族的仕进、贪赃被查的可能，以及在任者被告发下狱的风险。
- **家境之差**：家境分赤贫、贫寒、温饱、小康、殷实、富足、豪富几档，并随田产、人口、财力逐年变化（户籍简里随时可见）。同样是一年，赤贫人家的孩子剥榆树皮、光脚过冬、被送去给人放牛，弟妹可能被送人；小康人家过年有新衣、腊日分一块肉；富户的孩子有长工、先生、丝履；高门子弟有乳母和小僮，族祭时捧着祭器走在最前面。幼年还会遇到按家境出现的抉择：把最后半块饼让给弟妹、替大户看鸭子换一升米、处置偷粮的佃户孩子、替挨打的小僮认错。连生病、失火、遭贼的写法和轻重，也随家境不同。
- **出生时的家境说明**：降生页用白话说明你家在当时处在什么水平（每口人几亩田、够不够吃、十户人家里有几户比你难），不熟悉汉末也能看懂。
- **传家**：死后可以以子孙之身继续，家谱一代代接下去。
- **后记与身后**：结局按你的身份与死因写一段后记，并记下你死后故乡又经历了什么；家人一栏列出每位亲人的生卒与结局。
- **户籍简**：按走马楼吴简的格式（大男/大女、使男/使女、未使，虚岁、廿卅卌）记录你家的户口。
- **汉纪 · 一格一年**、生存曲线、同时代人的死因、墓志、同一时辰降生的另外三人。
- **从军之路**：成年男子可以把"眼下所重"放在"投军从戎"，乱世里更容易被收进军中；有膂力或尚武的人更常被募兵找上门。士族子弟或天生武勇的人投军，起步就是屯长。
- **名字分贵贱**：士族、县吏之家多取雅名（彧、琬、徽、珮）与吉字小名（阿璋、阿凤）；农家多取贱名（狗、丑、豚、黑）、排行或"弟""取"之类盼子的名字；奴婢的名字由主人起（奴福、秋菊）。士族女子读《女诫》、习女红，婢女在灶下与针线间度日；寡妇改嫁的可能也随门第而异。
- 九种出生方式（史实人生、生于熹平、生于中平、生于建安、三国鼎立、魏晋之际、生于太康、乱世之子、真正的随机）以及"我若生于那个时代"——除了性别、地区、家境、学历，还可以填想降生的年代、职业方向、性子与身体，它们会改变出身的权重、性情与天资。
- 每一世都有"命数"，可以重现同样的出身。

**这是历史概率模拟，而非精确人口学重建。**

## 运行

纯静态页面，没有构建步骤。直接用浏览器打开 `index.html`，或者：

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000
```

也可以直接部署到 GitHub Pages。前世与名册只保存在浏览器的 localStorage 中。

## 结构

| 文件 | 内容 |
|---|---|
| `js/data.js` | 郡国人口、各区人口指数、政权时间线、年号、族群、姓名、身份阶层 |
| `js/history.js` | 编年大事（效果按年份 × 地区）、战役、追随者旅程、历史人物与邂逅、地方风物、日常 |
| `js/engine.js` | 逐年模拟引擎（可确定性重现：同一命数 + 同样选择 = 同样一生） |
| `js/ui.js` | 界面、播放、舆图、汉纪、生存曲线、墓志、名册与前世 |
| `css/style.css` | 帛书与竹简的视觉 |

引擎不依赖 DOM，可以在 Node 中加载 `data.js`、`history.js`、`engine.js` 后批量模拟。
