# 日本語版の翻訳ルール（五千万分之一 → 日本語）

あなたは中国語で書かれたブラウザゲーム（後漢末〜三国〜西晋〜東晋の庶民の一生をシミュレートする）のソースコード断片を、日本語版に翻訳する。
断片は大きな JS/HTML ファイルの一部であり、単体では構文として完結しない。**コードの構造は一切変えず、プレイヤーに表示される文字列だけを日本語にする。**

## 出力
- 入力ファイル `X.txt` と同じディレクトリに `X.ja.txt` を書き出す（Write ツールで一度に全体を書く。大きすぎる場合は分割して Write → Edit で追記してよい）。
- **行数は入力と完全に同じ**にすること（1 行 → 1 行）。行の追加・削除・結合をしない。
- 書き終えたら `wc -l` で入力と出力の行数が一致することを確認する。

## 翻訳する対象
- 文字列リテラル（'…'、"…"）のうち、プレイヤーに表示される文・句（イベント文、選択肢、結果、説明、UI ラベル、ボタン、ツールチップ、エンディングの文章など）。
- index.html では、表示されるテキストノードと title / aria-label / placeholder 属性。

## 翻訳してはいけないもの（そのまま残す）
- コード、変数名、関数名、プロパティ名、オブジェクトのキー（`{ 书佐: 1.3 }` のような中国語キーも含む）。
- 正規表現リテラル（`/县令|太守/` など）。
- 比較・判定に使われる文字列：`=== '…'`、`!== '…'`、`indexOf('…')`、`case '…':`、`.test(...)` に関係するもの。
- 次のプロパティの値：`id`、`k`、`key`、`g`（支出グループ名）、`cls`、`rel`、`fk`、`job`、`office`、`f`、`zones`、`jun`、`who`。
- **短い名詞の用語**（句読点を含まない 4 字以内の語）で、人名・地名（州・郡・県・城）・勢力名・王朝名・元号・官職名・職業名・身分名・軍職名・称号を表すもの。例：'书佐'、'工匠'、'农'、'县令'、'屯长'、'曹操'、'洛阳'、'魏'、'黄初'、'佃户'、'士人'。これらは他のファイルで比較に使われていることがあるので、**簡体字のまま一字も変えない**。
- 人名・地名・勢力名は文中でも原文の漢字（簡体字）のまま残す（例：「曹操は许都に…」は「曹操」「许都」をそのまま）。
- プレースホルダー：`{kin}` `{friend}` `{who}` `{dest}` `{n}` `{a}` `{k}` `{lord}` `{clan}` `{school}` `{birth}` `{曹操}` `{刘备}` `{孙权}` `{汉帝}` など波括弧で囲まれたものは一字も変えない。
- コメント（`//`、`/* */`、`<!-- -->`）は翻訳しなくてよい（そのまま残す）。

## 文体
- 自然で読みやすい日本語の語り。地の文は常体の過去形（〜した／〜だった）。説明・UI ラベルは簡潔に。
- 「你」は「あなた」。ただし日本語として不自然なら主語を省いてよい。「他/她」は「彼/彼女」。
- 単位：钱→銭、亩→畝、石→石、斗→斗、岁→歳、年→年。数値表現（漢数字が後から差し込まれる場合も）はそのまま通じるようにする。
- 史書・古典の引用（例：「上品无寒门，下品无势族」「宁为国家鬼」）は原文の漢文を「」で残し、必要なら直後に短い日本語訳を添える。
- 原文の引用符（"…"、“…”）は日本語のかぎ括弧「…」に変える。**シングルクォートで囲まれた JS 文字列の中に半角の ' を入れない**（構文が壊れる）。ダブルクォート文字列の中に半角の " を入れない。
- 文字列の連結（`'你被抬进了' + n + '的府里'` など）は、連結した結果が自然な日本語になるように各断片を訳す（例：`'あなたは' + n + 'の屋敷に迎え入れられた'`）。どうしても語順が合わない場合に限り、同じ変数・同じ式を使ったまま連結の順序を最小限入れ替えてよい。
- 時代考証的な用語（屯田、户调、九品中正、察举、孝廉、太学、部曲、坞壁、罢癃 など）は日本語の漢字表記（屯田、戸調、九品中正、察挙、孝廉、太学、部曲、塢壁、罷癃）にしてよい（ただし上の「短い名詞の用語」がプロパティ値・比較に使われている場合はそのまま）。

## 迷ったら
- その文字列がプレイヤーに表示される文章なら訳す。表示されない識別子・キー・比較用の語なら残す。
- 判断がつかない短い語（4 字以内）は残す。


## 現在の状態
- 初回の翻訳は `ja/parts/` の断片から組み立て、OpenCC（s2t → t2jp、ただし「里」は保護）で日本の字体に変換した。
- **以後は `ja/js/` と `ja/index.html` が日本語版の正本**。中国語版に機能を追加したら、同じ変更を日本語の文面で `ja/js/` にも加えること。
- 同じ命数で中国語版と日本語版の人生が一致するか（`scratchpad/test/cmpja.js`）で、翻訳がロジックを壊していないか確かめられる。
